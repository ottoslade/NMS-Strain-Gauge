Notice!
The folder is here to contain the "./dbcc" executable was compiled using the dbcc library located in `nms-electronics/tools/dbcc`.
All of the source code and instructions to build the program can be also found at https://github.com/howerj/dbcc

You can compile the dbcc library locally and then move the `dbcc` executable into this folder. Then, run the `nms-electronics/shared/dbc_to_c/DBCtoCgenerator.py` python script to generate code in the `nms-electronics/shared/dbc_to_c/generated_code` folder.
